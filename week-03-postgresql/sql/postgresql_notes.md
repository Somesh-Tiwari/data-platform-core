# PSQL Commands and their uses
\d            :for database content
\dt           :for showing on tables present in the database
\d table_name :for showing the columns in table 
\c database_name  :for switching the database
\l             :for listing the database


# SQL notes
'*' in select statement means select all
ASC is for Ascending and DESC is for Descending order in ORDER BY clause
